# Student Account Application Test Plan

This plan describes the current business logic and implementation behavior of the COBOL account-management application. It is intended for business-stakeholder validation and as a baseline for unit and integration tests during the Node.js migration.

The application starts each process with a balance of `1000.00`. Test cases that depend on a starting balance should be run in a fresh application process, or the account should otherwise be reset to that value before execution.
